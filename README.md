# Python Data Project

This repository holds my Python data analytics work.

## 👉 Main Project: [Data Job Market Insights](./Data_Job_Market_Insights)

An end-to-end Python analysis of the India Data Analyst job market, covering skill demand, 2023 trends and salaries, to answer one question: **which skills should an aspiring Data Analyst learn first?**

**[Read the full project README →](./Data_Job_Market_Insights/README.md)**

The project folder contains:
- Five analysis notebooks, from EDA to optimal-skills analysis
- Charts exported to `images/`
- A detailed README covering the workflow, data cleaning, techniques and key insights

**Tools:** Python, pandas, matplotlib, seaborn, Jupyter
